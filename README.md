# Личное расписание Валентины

Планировщик занятий по русскому языку и литературе: неделя, добавление и удаление уроков, проверка пересечений, экспорт и импорт JSON.

Контакты на сайте отсутствуют. Расписание хранится в localStorage только в текущем браузере и не отправляется на сервер. Синхронизации и авторизации нет. Страница на GitHub Pages публичная; данные занятий не входят в репозиторий. Используйте резервные копии для переноса и сохранности данных. Время занятий московское (UTC+3).

## Запуск

```sh
python3 -m http.server 8000
```

Откройте страницу через HTTP. Сборка и зависимости не требуются.

## Публикация

Settings → Pages → Source → GitHub Actions. Workflow публикует сайт при push в main. При первом включении Pages запустите Publish website вручную во вкладке Actions, если предыдущий запуск завершился ошибкой.
