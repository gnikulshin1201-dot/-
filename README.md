# Валентина — русский язык и литература · ЕГЭ

Адаптивный сайт подготовки к ЕГЭ на русском языке. HTML и CSS, без сборки и зависимостей.

## Локальный запуск

```sh
python3 -m http.server 8000
```

## Публикация

В настройках репозитория откройте Settings → Pages → Source → GitHub Actions.
Workflow `.github/workflows/pages.yml` публикует сайт при push в `main` или ручном запуске.

На странице представлены русский язык и литература. Для записи добавлена кнопка звонка по номеру, предоставленному владельцем.

Тексты и ссылки редактируются в `index.html`, оформление — в `style.css`.
Внешний шрифт Manrope загружается с Google Fonts; без сети используется Arial.
